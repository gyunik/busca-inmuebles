# Motor RE/MAX (`remax_scraper.py`)

## Características
- **Portal:** RE/MAX Argentina
- **Volumen Ingestado:** 979 propiedades
- **Estrategia:** Conexión directa a API REST `api-ar.redremax.com/remaxweb-ar/api/listings/findAll` y extracción de imágenes CDN CloudFront (`d1acdg20u0pmxj.cloudfront.net`).
- **Ventaja Técnica:** Alta velocidad de extracción, datos enriquecidos de agentes inmobiliarios y coordenadas GPS nativas exactas.

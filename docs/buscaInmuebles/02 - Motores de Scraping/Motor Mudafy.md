# Motor Mudafy (`mudafy_scraper.py`)

## Características
- **Portal:** Mudafy Argentina
- **Volumen Ingestado:** 95 propiedades
- **Estrategia:** Consulta a API JSON de Mudafy con información curada de propiedades en barrios de alta demanda en CABA (Palermo, Belgrano, Recoleta).

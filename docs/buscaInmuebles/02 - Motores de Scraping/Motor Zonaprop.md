# Motor Zonaprop (`zonaprop_scraper.py`)

## Características
- **Portal:** Zonaprop Argentina
- **Volumen Ingestado:** 3.266 propiedades
- **Estrategia:** Extracción de datos embebidos Next.js / HTML con headers rotativos para evitar bloqueos por rate limit.
- **Campos Obtenidos:** Título, precio en USD, expensas, ubicación precisa, $m^2$ totales y cubiertos, dormitorios, baños, fotos en alta resolución.
